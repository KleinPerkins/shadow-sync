## Native and visual acceptance

No new drawing asset or interaction is introduced. Retain the existing AppKit controls and icon provenance. Validate keyboard-only dismissals, unchanged menu/help copy, VoiceOver help, light/dark appearance, and minimum/larger supported window geometry on a native desktop. Automated metadata evidence is separate from physical/visual UAT acceptance. Open physical acceptance does not become a generic operator code-review gate; it remains an explicit product-acceptance milestone.
