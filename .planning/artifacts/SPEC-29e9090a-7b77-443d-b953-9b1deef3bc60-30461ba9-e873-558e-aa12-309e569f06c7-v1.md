# Foreground ownership and deferred Quit correction contract

## Requirement and design traceability

This component implements PRD v3 REQ-SF-05, REQ-GV-06–08/11 and REQ-RL-05/06 and the companion UXR-NC-01–04/design contract. PLAN v3 retains all broader extraction, safety, signing, migration and acceptance gates. Application ownership is limited to `Sources/ShadowSyncApp/AppDelegate.swift` and regression cases in `Sources/ShadowSyncApp/M5Harness.swift`; the release engineer maintains exact native report registration and test receipts. No installed application or external policy changes belong to this component.

## Observed defects and boundary

The unpublished candidate has two reproducible product failures. Foreground timeout retires the pending request but leaves a published failure without a target owner, so later dismissal fails to clear the menu/tooltip/accessibility help. During authority-update Quit, the first barrier stores admission=false; after the update settles, recombining that historical false value leaves Quit blocked even though current authority and inventory are settled.

Candidate AppDelegate input SHA-256 is `34d81bb5ef1c5d1bc517a83036ba9b574af0cdfdc33eeb26a79fc92169c6b612`; M5Harness input SHA-256 is `0ddb4a8da639d3e7266a04a498b967ae732e8c9d0bc9662266b58e0fabb00343`. Diagnostic instrumentation is excluded from product changes.

The separate takeover failure occurs at a refused child spawn in the fork-denying fixture sandbox. The worker-stop test also needs child execution, and the combined UI test expects a missing source-document taxonomy. These remain unresolved qualification dependencies under P3-CI-01; this correction does not waive them, weaken sandboxing, remove assertions, or claim takeover is defective.

## Falsifiable technical contract

Track a weak reference to the controller owning the published foreground failure. Set it when publishing the failure and clear it whenever the failure is cleared. The shared ordinary-target dismissal handler clears the published failure only for that exact controller, including when the original pending request has already ended. Keep inline-message priority and unrelated messages intact; restore shortcut help consistently. A stale dismissal or another controller's dismissal cannot clear the current owner's failure. The separate operation-contention dismissal/reconciliation path remains unchanged: without a valid primary target it preserves the failure, and a valid target clears it only after established foreground reality. Existing success/supersession and both contention cases remain mandatory in the foreground suite.

Recompute foreground-run admission on every Quit attempt from the current run controller, or from the absence of any run controller. Combine that fresh result with current inventory and Body3 settlement. Never overwrite active-run admission evidence with an unconditional no-work result. Preserve current child-reaping, worker-terminal, confirmation, transaction, preference, lifecycle-authority and generation predicates and the existing exactly-once termination consumer.

Authority-update admission must refuse once lifecycle exit has begun, including pending and already consumed termination states. Use the router's lifecycle phase/admission contract rather than a boolean that clears at termination. A completion releases only its matching authority token. Stale and duplicate callbacks cannot clear a current token, start inventory, reopen UI, or cause another termination. This repair changes no persistence schema, lock namespace, release trust or process-signal behavior.

## Failure handling and rollback

All uncertain drain evidence continues to refuse termination and retains owned state. The repair introduces no reset, process-kill bypass or dropped wait. Source rollback reverts this component through ordinary governed delivery while retaining failing evidence; it does not modify installed state. An unproven case blocks component completion. No public source export, release, installation or UAT acceptance is implied by passing this component.
