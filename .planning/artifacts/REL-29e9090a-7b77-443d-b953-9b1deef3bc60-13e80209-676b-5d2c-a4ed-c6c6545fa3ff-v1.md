# MVP signed distribution packaging qualification

Status: implementation qualification only. No product has been submitted to Apple, published, installed or accepted by this record.

## Requirement binding

Implements the notarization and stapling portion of RL-01/RL-02 and the distribution-layout portion of MG-01 under accepted ADR 0008 and the MVP-first PRD/plan. Sparkle and feed promotion remain deferred. The signed lifecycle coordinator still requires installation and migration integration before release qualification.

## Current packaging behavior

`scripts/notarize-release-bundle.py` accepts only an exact source-bound `release-assembly.json` and unchanged Developer ID signed payload. The caller supplies an isolated keychain path, stored notary profile name and signing identity fingerprint. The tool does not read secret values, install the product or publish a release.

An owner-private attempt directory and exclusive lock serialize the transaction. App ZIP and DMG submission IDs, submitted digests and Apple acceptance logs are retained. Unknown upload completion refuses automatic resubmission. Explicit `--resume` accepts only the same source, assembler, packager, publisher and artifact bindings. The submitted DMG remains immutable while its distribution copy is stapled; retries recheck the signed code identity. All signed payload bytes remain unchanged except the exact bounded Apple ticket location, `Contents/CodeResources`.

The app and disk image require accepted notarization, ticket validation, Developer ID verification and Gatekeeper assessment. Final evidence binds source revision/digest, version/build, publisher, submission IDs and distributed artifact digest. A completed package receipt still records publication, installation and product acceptance as false.
